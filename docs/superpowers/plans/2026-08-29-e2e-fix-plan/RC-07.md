# RC-07 — Align client route guards, nav and page data sources with server procedure roles (voluntario/beneficiario)

> Part of [2026-08-29 E2E fix plan](../2026-08-29-e2e-fix-plan.md). **REQUIRED SUB-SKILL:** use `superpowers:subagent-driven-development` or `superpowers:executing-plans`. Steps use checkbox (`- [ ]`) syntax for tracking.

**Severity:** high · **Status at HEAD:** open · **Estimate:** 150 min · **Findings:** F011, F046, F054, F108, F109, F113, F142, F191, F237

**Goal:** Make the client's role surface match the server's tRPC guards so (1) beneficiarios never land on staff screens that fail silently (/checkin, /personas*, /programas* get requiredRoles; the mobile footer filters by role — F011, F046, F113), (2) voluntarios get working Programas pages via the voluntario-safe procedures (programs.getAll; getBySlug opened to voluntario with volunteer_can_access filtering — F109, F142), (3) voluntarios can print a QR after registering (PersonaQR reads persons.getQrPayload instead of admin-only persons.getById; the wizard redirects volunteers to /personas/:id/qr — F054), (4) the volunteer reparto close-out flow is reachable without dead admin buttons (RepartoTab/RepartoList gated by isAdmin — F191), (5) FORBIDDEN is rendered as an explicit Spanish message instead of fake empty states (/familias/entregas — F108), (6) admins are not offered the superadmin-only 'Editar' on instituciones (F237), and (7) the auth guard messages are Spanish (shared/const.ts, trpc.ts:135 — F011/F237).

**Rationale:** Root cause: client route guards, nav items and page code were written against a looser permission model than the server actually enforces (ADR-0002 makes tRPC guards the only PII wall, so the server is right and the client is wrong). Every affected page swallows FORBIDDEN into an empty/'no encontrado' state, so volunteers at the counter see blank screens with no explanation — the volunteer reparto close-out (server-designed for voluntario: rounds-closeout.ts procedures are voluntarioProcedure) is unreachable, and beneficiarios get dead footer tabs. Verified at HEAD (post #152/#154): App.tsx:97-136 bare ProtectedRoute; MobileFooterNav.tsx:11-15 unfiltered; Programas.tsx:24 uses adminProcedure getAllWithCounts; programs.ts:150 getBySlug adminProcedure; FamiliasEntregas.tsx:32 admin-only families.getAll with '.data'-only destructure; PersonaQR.tsx:12 usePersonById (admin-only by design, #46); ProgramTabs.tsx:155 drops isAdmin; _InstitucionRow.tsx unconditional Editar; shared/const.ts:4-5 English. Findings: F011, F046, F054, F108, F109, F113, F142, F191, F237. Routes unblocked: /checkin, /personas, /personas/:id/qr, /programas, /programas/:slug, /familias/entregas, /admin/instituciones.

    <nav

      aria-label="Navegación principal"

            location === item.href ||
            (item.href !== "/" && location.startsWith(item.href));

            <Link key={item.href} href={item.href}>

                className={cn(
                  "flex flex-col items-center justify-center gap-0.5 min-w-[64px] h-16 px-2 cursor-pointer transition-colors",
                  active
                    ? "text-primary"
                    : "text-muted-foreground hover:text-foreground"

                title={item.label}

                <span className="shrink-0">{item.icon}</span>

                {active && (
                  <span className="w-1.5 h-1.5 rounded-full bg-primary mt-0.5" aria-hidden="true" />
                )}
              </div>
            </Link>
          );
        })}
      </div>
    </nav>
  );
}

/**

  const { data, isLoading, error } = trpc.programs.getAll.useQuery(undefined, {
    staleTime: 5 * 60 * 1000, // 5 minutes
    enabled,
  });

  return {
    programs: data ?? [],

    error,
  };
}

    staleTime: 2 * 60 * 1000, // 2 minutes
    enabled,
  });

  return {
    programs: data ?? [],

}
